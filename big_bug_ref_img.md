# Gemini-FastAPI 参考图片生成失败的重大 Bug 修复记录

## 问题描述

当使用 Gemini-FastAPI 的 `/v1/responses` 端点进行**带参考图片**的图片生成时，后端无法返回生成的图片 URL，导致：
- 前端收到 502 错误
- 返回的图片 URL 是占位符：`http://googleusercontent.com/image_generation_content/0`
- 实际上 Gemini 已经成功生成了图片（在 Gemini 网页端可以看到）

## 根本原因

这是 `gemini-webapi` 库（v1.17.3）的已知 Bug：
- GitHub Issue: https://github.com/HanaokaYuzu/Gemini-API/issues/194
- 问题：`response.images` 返回空列表，即使图片已成功生成
- 错误信息：`Safe navigation: path [4] ended at index 0`
- 这是账号相关的问题，gemini-webapi 无法正确解析响应中的图片数据

## 解决方案

采用 **Monkey Patching** 方式拦截原始 HTTP 响应，在 gemini-webapi 解析之前提取真实的图片 URL。

### 核心修改文件

`/root/tread/Gemini-FastAPI/app/server/chat.py`

### 关键代码修改

#### 1. 全局变量存储原始响应（第 22 行）
```python
# Global variable to store raw Gemini responses for debugging
_last_raw_gemini_response: dict | None = None
```

#### 2. Monkey Patch HTTP 客户端（第 1408-1508 行）
```python
async def _monkey_patch_http_client_for_raw_response(session: ChatSession):
    """
    拦截 HTTP 客户端，在 gemini-webapi 解析之前捕获原始响应
    """
    global _last_raw_gemini_response

    # 获取 session 的 HTTP 客户端
    client = session.geminiclient
    http_client = client.client  # httpx.AsyncClient

    # 保存原始的 post 方法
    if not hasattr(http_client, '_original_post'):
        http_client._original_post = http_client.post

    # 创建包装器拦截响应
    async def post_wrapper(*args, **kwargs):
        global _last_raw_gemini_response  # ⚠️ 关键：必须声明 global

        response = await http_client._original_post(*args, **kwargs)

        if response.status_code == 200:
            response_text = response.text
            try:
                _last_raw_gemini_response = json.loads(response_text)
            except:
                # Gemini 响应不是纯 JSON，保存为原始文本
                _last_raw_gemini_response = {'_raw_text': response_text}

        return response

    # 应用 monkey patch
    http_client.post = post_wrapper
```

**重要 Bug 修复**：在嵌套的 `post_wrapper` 函数中，必须显式声明 `global _last_raw_gemini_response`，否则会创建局部变量而不是修改模块级全局变量。

#### 3. 从原始响应提取图片 URL（第 1302-1348 行）
```python
async def _fetch_generated_images_from_raw_response() -> list[str]:
    """从捕获的原始响应中提取 googleusercontent.com 图片 URL"""
    global _last_raw_gemini_response

    if not _last_raw_gemini_response:
        return []

    # 处理原始文本格式
    if isinstance(_last_raw_gemini_response, dict):
        if '_raw_text' in _last_raw_gemini_response:
            search_text = _last_raw_gemini_response['_raw_text']
        else:
            search_text = json.dumps(_last_raw_gemini_response)

    # ⚠️ 关键修复：区分生成图片和参考图片的 URL
    # 生成的图片使用 /gg-dl/ 路径，参考图片使用 /gg/ 路径
    url_pattern_generated = r'(https?://(?:lh\d+\.)?googleusercontent\.com/gg-dl/[^\s\'"<>\\]+)'
    url_pattern_reference = r'(https?://(?:lh\d+\.)?googleusercontent\.com/gg/[^\s\'"<>\\]+)'

    # 优先查找生成图片 URL（gg-dl）
    matches = re.findall(url_pattern_generated, search_text)

    # 如果没找到生成图片，回退到参考图片 URL（向后兼容）
    if not matches:
        matches = re.findall(url_pattern_reference, search_text)
        logger.info("⚠️ No /gg-dl/ URLs found, using /gg/ URLs instead")

    return list(dict.fromkeys(matches))  # 去重
```

#### 4. 下载图片并创建 GeneratedImage 对象（第 1351-1401 行）
```python
async def _fetch_generated_images_workaround(session: ChatSession, rcid: str) -> list[GeneratedImage]:
    """
    Workaround：从原始响应提取 URL 并下载图片
    """
    image_urls = await _fetch_generated_images_from_raw_response()

    if not image_urls:
        return []

    # 获取 Gemini 客户端的 cookies（用于认证）
    cookies = None
    if hasattr(session, 'geminiclient') and hasattr(session.geminiclient, 'cookies'):
        cookies = session.geminiclient.cookies

    # ⚠️ cookies 是必需的
    if not cookies:
        logger.warning("No cookies available, cannot create GeneratedImage objects")
        return []

    # 下载图片
    generated_images = []
    async with httpx.AsyncClient(
        timeout=30.0,
        follow_redirects=True,  # ⚠️ 必须跟随重定向
        cookies=cookies          # ⚠️ 必须使用认证 cookies
    ) as http_client:
        for idx, url in enumerate(image_urls):
            response = await http_client.get(url)
            response.raise_for_status()

            # ⚠️ GeneratedImage 必须提供 cookies 字段
            img = GeneratedImage(
                url=url,
                title=f"Generated Image {idx+1}",
                alt=f"Image generated by Gemini",
                cookies=cookies  # 必需字段
            )
            generated_images.append(img)

    return generated_images
```

if files and hasattr(result, 'candidates') and result.candidates:

## 关键技术点

### 1. 区分生成图片和参考图片 URL（⭐ 最关键）
**发现**：
- 🎯 **生成的图片** URL 路径：`/gg-dl/` (download)
- 📎 **参考图片** URL 路径：`/gg/`

**问题**：
如果不区分这两种 URL，会把用户上传的参考图当作生成的图片返回。

**解决方案**：
1. 优先使用正则匹配 `/gg-dl/` 路径的 URL（真正生成的图片）
2. 如果没找到，才回退到 `/gg/` 路径（保持向后兼容，用于不带参考图的纯文本生图）

```python
# 生成图片 URL 正则（优先）
url_pattern_generated = r'(https?://(?:lh\d+\.)?googleusercontent\.com/gg-dl/[^\s\'"<>\\]+)'

# 参考图片 URL 正则（回退）
url_pattern_reference = r'(https?://(?:lh\d+\.)?googleusercontent\.com/gg/[^\s\'"<>\\]+)'
```

### 2. 嵌套函数中的全局变量
**错误写法**：
```python
async def outer():
    global _var

    async def inner():
        _var = "value"  # ❌ 创建了局部变量，不会修改全局变量
```

**正确写法**：
```python
async def outer():
    global _var

    async def inner():
        global _var  # ✅ 必须在嵌套函数中再次声明
        _var = "value"
```

### 3. HTTP 重定向处理
Google 图片 URL 会返回 302 重定向，必须使用 `follow_redirects=True`：
```python
async with httpx.AsyncClient(follow_redirects=True) as client:
    response = await client.get(url)  # 自动跟随 302 → 200
```

### 4. Cookie 认证
Google 图片需要使用 Gemini 客户端的 cookies 进行认证，否则会返回 403 Forbidden。

### 5. GeneratedImage 必需字段
`GeneratedImage` 是 Pydantic 模型，必须提供 `cookies` 字段：
```python
class GeneratedImage(Image):
    cookies: dict[str, str]  # 必需字段

    @field_validator("cookies")
    @classmethod
    def validate_cookies(cls, v: dict) -> dict:
        if len(v) == 0:
            raise ValueError("GeneratedImage requires non-empty cookies")
        return v
```

## 修复的 Bug 列表

1. ✅ Session 属性路径：`session.geminiclient.client` 是 `httpx.AsyncClient`
2. ✅ 全局变量作用域：嵌套函数必须显式声明 `global`
3. ✅ JSON 解析失败：Gemini 响应不是纯 JSON，需要保存为原始文本
4. ✅ HTTP 302 重定向：需要 `follow_redirects=True`
5. ✅ HTTP 403 认证：需要传递 Gemini 客户端的 cookies
6. ✅ Pydantic 验证错误：`GeneratedImage` 必须提供 `cookies` 字段
7. ✅ **URL 混淆问题**：区分 `/gg-dl/`（生成图）和 `/gg/`（参考图）路径
